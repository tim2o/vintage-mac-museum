I collect vintage Macintosh computers, keep them running, and write down what they are. This site is the shelf where all of it lives. It has three jobs: preserving the machines, archiving what they look like and what is inside them, and having fun with them.

## Preserving

Old Macs do not last by themselves. Capacitors leak, batteries die, hard drives wear out, and plastics turn brittle. I try to keep each machine working, using the operating system it was made for wherever I can. Some have had a worn-out hard drive swapped for a modern solid-state card on an adapter, and some are waiting on a repair. When a machine does not work, its page says so and says what I know about why, because a machine that is documented as broken is easier to fix later than one that was never recorded.

## Archiving

Every machine gets its own page, listed from oldest to newest in [the collection]({{ '/' | url }}). Each one has photos, the specifications as the machine itself reports them (usually from System Profiler or About This Computer), and a plain note on its condition. Where I have filled in a detail from Apple's published documentation instead of the machine, the page says so. Serial numbers and anything personal are blurred out of the photos. The aim is a record that is accurate enough to trust and that someone else could use when they are trying to identify, repair, or restore the same model.

## Having fun

These machines were built to be used, and a lot of the joy is in using them: bringing one back to life, seeing it run the software of its own era, and filming it. The montage videos on the home page come from that.
If you collect, restore, or just remember these computers, I hope you find something here worth looking at.
