A PowerBook G3 Lombard running Mac OS X 10.2.8. Apple System Profiler reports a 400 MHz G3 on a 67 MHz bus with a 1 MB L2 cache, and two memory modules, 256 MB in the bottom slot and 128 MB in the top slot. The desktop shows disks named Jaguar, Mac OS 9.2.2, OS X b2 and Panther.
